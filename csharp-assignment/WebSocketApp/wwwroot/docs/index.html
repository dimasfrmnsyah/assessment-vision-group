Student REST API

Create, read, update, and delete student records. Built with C#, ASP.NET Core, and SQLite.

Public API base URL

https://csharp.dimasfrmnsyh.my.id

For local development, use http://localhost:5000 as the API base URL. This documentation page is served by the web app on port 5001 locally.

This is a public assignment demo without authentication. Anyone can read or modify records. Use fictional data only. The examples below execute against the public API when copied into your terminal.

Endpoints

MethodPathDescriptionSuccess
GET/studentsList all students200
GET/students/{id}Get one student200
POST/studentsCreate a student201
PUT/students/{id}Replace all editable fields200
DELETE/students/{id}Delete a student204
GET/api-healthAPI availability through the public proxy200

{id} is an integer returned when a student is created. The local API health endpoint is /; the public proxy exposes it at /api-health.

Request and response fields

POST and PUT accept JSON with Content-Type: application/json. All three fields are required. PUT is a full replacement, not a partial update.

FieldTypeRule
idintegerGenerated by the server; returned in responses
namestringMust not be empty or whitespace
emailstringMust pass email address format validation
majorstringMust not be empty or whitespace

Leading and trailing whitespace is removed before saving. Email format validation does not verify mailbox ownership.

Examples

1. Create a student

curl -i https://csharp.dimasfrmnsyh.my.id/students \
  -H 'Content-Type: application/json' \
  -d '{"name":"Demo Student","email":"demo@example.com","major":"Computer Science"}'

Response: 201 Created, with a Location: /students/1 header and a JSON body. Your ID may differ; use the returned ID in subsequent requests.

{"id":1,"name":"Demo Student","email":"demo@example.com","major":"Computer Science"}

2. List students

curl -i https://csharp.dimasfrmnsyh.my.id/students

Response: 200 OK, with a JSON array of student objects. An empty database returns []. There is no pagination or filtering.

3. Get a student

curl -i https://csharp.dimasfrmnsyh.my.id/students/1

Response: 200 OK, with one student object, or 404 Not Found.

4. Update a student

curl -i -X PUT https://csharp.dimasfrmnsyh.my.id/students/1 \
  -H 'Content-Type: application/json' \
  -d '{"name":"Updated Student","email":"updated@example.com","major":"Mathematics"}'

Response: 200 OK, with the updated student object. All three editable fields must be supplied.

5. Delete a student

curl -i -X DELETE https://csharp.dimasfrmnsyh.my.id/students/1

Response: 204 No Content, with no response body. Repeating the deletion returns 404.

Error responses

400 — Invalid input

Missing or invalid fields return a validation problem response. For example, an empty JSON object returns these field errors within the response:

{
  "status": 400,
  "errors": {
    "name": ["Name is required."],
    "email": ["A valid email address is required."],
    "major": ["Major is required."]
  }
}

This excerpt omits standard problem metadata. Malformed JSON can also return 400 with a different body. Use the HTTP status to handle failures.

404 — Student not found

{"message":"Student not found."}

Returned for a missing student ID on GET, DELETE, or a valid PUT request. PUT validates its input before checking whether the student exists.

415 — Unsupported media type

Send POST and PUT requests using Content-Type: application/json.

Student records are stored in SQLite and persist across service restarts.
